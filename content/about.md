# Hi, I'm Dron 👋

I'm a **Cybersecurity Engineer and aspiring Penetration Tester** focused on understanding how systems break, how vulnerabilities can be discovered, and how they can be exploited and remediated.

My primary interests are **penetration testing, web application security, API security, offensive security, and vulnerability research**.

I use this site to document my learning, CTF solutions, security research, technical experiments, and practical methodologies.

---

## 🛡️ What I Work On

### Offensive Security

My main focus is developing practical offensive-security skills through hands-on labs, CTFs, vulnerability research, and penetration-testing exercises.

Areas I'm actively working on include:

* Web application penetration testing
* API security testing
* Authentication and authorization testing
* Access control vulnerabilities
* XSS, SQL injection, SSRF, CSRF and related web vulnerabilities
* Reconnaissance and attack-surface discovery
* Vulnerability validation and exploitation
* Security automation and tooling

### 🔎 Security Research

I'm particularly interested in understanding **why vulnerabilities exist**, rather than simply relying on automated scanners.

My workflow typically involves:

```text
Reconnaissance
      ↓
Attack Surface Mapping
      ↓
Manual Testing
      ↓
Hypothesis
      ↓
Exploitation
      ↓
Impact Analysis
      ↓
Documentation
```

Automation helps me move faster, but manual analysis is where I focus on finding the issues that scanners often miss.
